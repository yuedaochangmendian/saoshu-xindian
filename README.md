# 扫书新典

离线 Android 扫书资料阅读器，界面参考“扫书宝典”的青绿色卡片、粉红色搜索栏与底部导航。

## 下载

GitHub Release 提供：

- Android APK：已签名、可直接安装的应用
- 完整源码包：源码、离线数据库与构建配置

## 数据

- `app/src/main/assets/saoshu.db`：72,061 条内容、27,123 个书名聚合、74,306 次来源关系
- 数据截止：2026-10-20
- 正文完整保留；标题、作者、书名建立本地索引，正文检索在需要时执行
- 已清理 1,719 条相似度不低于 99.5% 的重复正文，重复记录的来源关系会合并到保留版本
- 已过滤 430 条纯表情、占楼、催更、致谢和无信息短回复
- 已删除 2026-09-20 之后、有效正文不足 50 字的 966 条近期内容
- 安装包不携带 FTS 索引，首次启动时在设备本地生成，以减小 APK 并支持单文件发布

数据库文件约 169 MB，超过 GitHub 对单个普通仓库文件 100 MB 的限制，因此不提交到 Git 历史，而是放在 Release 的完整源码压缩包中。克隆源码后，将 `saoshu.db` 放入 `app/src/main/assets/` 即可构建。

## 功能

- 首页统计、类型快捷入口和最近收录
- 标题、作者、书名搜索，标题无结果时自动回退正文检索
- 分类与来源筛选
- 书名聚合、相关评论与楼内回复阅读
- 收藏、复制正文、打开原帖、多来源记录
- 上一篇/下一篇
- 本地删除、收藏与书库同步隐藏，可一键恢复
- 导出全部未删除扫书数据为 UTF-8 JSONL
- 导入扫码备份，按 `canonical_key` 查重并补充缺失来源
- 卡片、按钮、分类和列表提供水波纹与触觉按压反馈
- 卡片整块可点击；底栏在向下滑动时自动隐藏，停止后恢复
- 扫书正文自动整理字段、段落和重点标题
- 隐藏正文中的来源标注和合并记录，标题去除回复、楼中楼、时间和图片残片
- 松石绿、海盐蓝、琥珀棕、樱雾粉、暮云紫五种主题

## 数据管理

底部“数据”页提供：

- **导出扫书**：通过系统文件选择器保存 JSONL，包含正文、分类、书名关联与全部来源关系
- **导入扫书**：逐行读取并查重；新增内容会同步进入搜索和书名聚合
- **本地删除**：阅读页可删除单条内容，原内置数据库不受影响
- **恢复本地删除**：恢复所有本机隐藏记录

导出文件采用流式读写，避免把 75,000 余条正文一次性装入内存。

## 查重

内置数据库按正文标准化结果计算查重指纹，并使用前缀/后缀候选桶与完整文本相似度复核。阈值低于 99.5% 的内容不会自动删除，避免误删同一本书的不同观点。详细结果见 `app/src/main/assets/content_dedupe_report.json`。

维护工具：

- `tools/dedupe_app_content.py`：重建候选桶、复核相似度、合并来源并重建书名聚合
- `tools/filter_meaningless_replies.py`：过滤纯表情、占楼、催更、致谢和低信息短回复
- `tools/filter_recent_short.py`：删除近期有效正文不足 50 字的内容
- `tools/strip_app_search_index.py`：从随包数据库移除 FTS 索引，改由首次启动时生成

## 构建

需要 JDK 17+、Android SDK Platform 35 和 Build-Tools 35。

```powershell
gradle --offline assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。首次启动会把离线数据库复制到应用私有目录，随后完全离线运行。

## 技术栈

- Java / Android 原生 View
- SQLite 内置离线数据库
- FTS4 标题、作者与书名索引
- 无第三方运行时依赖
