# 扫书新典

离线 Android 扫书资料阅读器，界面参考“扫书宝典”的青绿色卡片、粉红色搜索栏与底部导航。

## 下载

GitHub Release 提供：

- Android APK：已签名、可直接安装的应用
- 完整源码包：源码、离线数据库与构建配置

## 数据

- `app/src/main/assets/saoshu.db`：130,681 条可读内容、76,689 个书名聚合、154,203 次来源关系
- 数据来源：《扫书宝典》3.10.250109、yy小说吧/哀伤雪刃吧提取表、优书网书评和 BookSift 书目评价，截止 2026-10-23
- 原库的 `clist` 38,594 条、`dalao` 2,400 条和 `wlist` 39 条已归一化到 `documents`，不再重复内嵌原始正文表
- `document_sources` 使用 `WITHOUT ROWID` 复合主键保存 `clist/dalao/wlist` 来源编号，避免额外索引
- 正文清理 HTML 后只存储一次，书名聚合和来源关系使用紧凑索引
- 合并两吧提取记录共 2,538 条；2,533 条唯一正文新增入库，5 条重复正文并入已有来源
- 提取表中的倾向、要点、标签、点赞数和楼层定位保存在 `extract_metadata`
- 优书网收录 59,831 本至少有一条 100 字以上有效书评的书籍，共纳入 222,245 条评论；清洗后较短的原始长评也不会被丢弃，每本聚合上限 4,000 字
- 优书网另收录 3,353 本当前书库命中书籍的评分与字数资料；2 个缺少书名的优书网书籍使用可追溯占位标题保留
- BookSift 的 47,448 条书目评价按规范化正文合并为 40,672 组，其中 16,741 组并入已有正文，其余 23,931 组新增入库
- 外部正文与现有书库按规范化正文哈希查重；重复正文只存一次并补充来源关系，避免保存整套原始帖子、楼层和图片表
- 不再使用此前合并库中的去重、短回复过滤和来源合并结果
- 安装包不携带 FTS 索引，首次启动时在设备本地生成，以减小 APK 并支持单文件发布

优书网与 BookSift 原始库合计约 828 MiB。经过正文查重、没有有效长评的目录裁剪、来源归并和 `VACUUM` 后，随包数据库约 332 MiB；文件仍作为 Release 源码包的一部分分发，不提交到 Git 历史。

## 功能

- 首页采用内容优先布局，仅保留轻量统计、搜索入口和随机“扫书 / 推书 / 避雷”，支持一键换一批
- 首页与详情响应优化：首页页面与统计计数缓存、随机池启动预热，切换标签不重建页面；上一篇/下一篇只按 id 查询，毫秒级响应
- 搜索、书库、收藏和数据管理页统一压缩标题、说明和筛选区域，内容更早进入首屏
- 数据管理将完整书库、用户数据和 WebDAV 合并为统一的“备份 / 恢复”中心
- 标题、作者、书名搜索，标题无结果时自动回退正文检索
- 搜索结果不设条数上限，并使用游标按需读取正文，避免一次加载全部结果
- 关键词搜索与标题/全文模式切换，不显示分类或来源标签
- 从首页新进入搜索页时清空输入框并自动弹出输入法；从内容详情返回时复用原搜索页与游标，不重新执行查询，并保留关键词、输入状态和列表位置；普通退出搜索页时释放缓存游标。输入为空时展示最近 10 条搜索记录，点击可直接再次搜索，也可一键清空
- 书库页提供“网络采集 / 名词解释”并列切换，切换滑块为胶囊形圆角、与容器曲线嵌套；采集结果由用户逐帖勾选后导入
- 从书名详情、正文详情或简记编辑页返回时，恢复进入前的列表位置
- 底部导航移除搜索标签，全文搜索改为从首页入口进入，并可返回进入前的页面
- 收藏、复制正文、打开原帖、多来源记录
- 上一篇/下一篇
- 本地删除、收藏与书库同步隐藏，可一键恢复
- 内置贴吧网络增量采集：支持匿名或加密 BDUSS 身份，读取 yy小说吧和哀伤雪刃，按吧保存水位、限速、预算与失败冷却
- 导出全部未删除扫书数据为 UTF-8 JSONL
- 导入扫码备份，按 `canonical_key` 查重并补充缺失来源
- 自绘 `FeedbackTextView` / `FeedbackLinearLayout` 统一处理水波纹、按压状态和触觉反馈
- 所有原生弹窗统一使用 24dp 圆角、描边、暗色背景和主题强调色
- UI 全面改版（v3.43，参考 Bettbox / Material 3 扁平表面风格）：页面标题区与系统栏统一使用表面色、按深浅色自适应图标，彩色渐变标题条全面移除；书名/正文详情头卡改用主题主色容器（浅底深字）；卡片统一 20dp 超椭圆圆角；底栏为近不透明（98%）悬浮胶囊 dock
- 搜索、详情和简记页左上角返回入口使用原生按钮，避免自定义触摸层拦截
- 标签页、详情页、名词页和简记页使用统一的淡入上移动画
- 底栏由专用 `NavTabView` 直接接管触摸并在抬手时切换页面；点击震动默认关闭，可在数据页开启
- 震动开关使用白色滑块和主题色轨道，选中/未选中状态颜色一致
- 卡片整块可点击；各搜索栏（首页搜索卡、搜索页输入栏、书库搜索框）与书库页切换滑块统一为胶囊形圆角；底栏为悬浮 dock 风格纯图标导航：白色（深色模式为深色）不透明背景、1dp 细描边、52dp 高胶囊圆角、左右 24dp 边距，选中项为主题强调色、未选中为灰色，不使用模糊效果；数据页可开启「底栏磨砂」让底栏呈半透明悬浮效果
- 色块上的文字（渐变标题条、书名聚合头卡、搜索按钮）带轻投影与微字距，白字边缘对比更清晰
- 扫书正文自动整理字段、段落和重点标题
- 隐藏正文中的来源标注和合并记录，标题去除回复、楼中楼、时间和图片残片
- 松石绿、海盐蓝、琥珀棕、樱雾粉、暮云紫五种主题（Miuix 蓝主题已移除，已选用户自动回退松石绿）
- 所有圆角均为自绘超椭圆（squircle）路径，转角比普通圆角更平滑，elevation 阴影与裁剪跟随形状（v3.42 起脱离主题全局生效）
- 深色模式自动跟随 Android 系统夜间模式，系统主题变化后重新同步全部页面、弹窗与系统栏
- 状态栏与系统导航栏跟随当前主题使用统一深色，并保持白色系统图标

## 数据管理

底部“数据”页提供：

- **导出扫书**：通过系统文件选择器保存 JSONL，包含正文、分类、书名关联与全部来源关系
- **导入扫书**：逐行读取并查重；新增内容会同步进入搜索和书名聚合
- **本地删除**：阅读页可删除单条内容，原内置数据库不受影响
- **恢复本地删除**：恢复所有本机隐藏记录
- **网络增量采集**：已移至书库页，可分别启停两个关注吧；冷启动回溯最近帖子，后续只采集水位后的新帖；采集后逐帖勾选导入
- **统一备份入口**：数据页只保留“备份”和“恢复”两个主按钮；完整书库、用户数据、WebDAV 和剪切板方式在圆角选择弹窗中分类展示
- **采集详情预览**：导入选择列表显示正文摘要；点击“查看详情”可阅读完整楼层正文、作者、时间、互动数据，并支持复制正文或打开原帖
- **采集参数**：每吧采集帖数、冷启动帖数、每帖楼层数和列表扫描页数均可调整，并持久化保存
- **单条导出**：阅读页可将当前扫书及全部来源导出为独立 JSONL
- **剪切板导入**：先弹出可编辑多行文本框并预填剪切板，确认后识别多条扫书并自动去重
- **统一用户数据备份**：本地文件与 WebDAV 使用同一份备份，包含收藏、简记、搜索记录、主题、震动设置以及 WebDAV 目录、文件名、账号和密码；不包含当前离线正文库
- **WebDAV 云同步**：配置、连接测试、上传备份和跨设备恢复合并到同一张卡片
- **WebDAV 凭据提示**：密码在应用本机使用 Android Keystore 的 AES-GCM 密钥加密；为了让另一台设备恢复连接，导出文件和云端备份会包含可恢复的登录信息，请只保存到可信位置
- **检查更新**：通过 GitHub Release 比较版本并打开新版 APK 下载页
- **更新镜像**：可选择 GitHub 原站、ghfast、gh-proxy 或 ghproxy 下载源
- **收藏与简记合并页**：收藏内容与本地便签使用同一个搜索框和统一列表，置顶简记优先、其余按日期混合排序；简记支持自动保存、置顶、软删除和回收站

导出文件采用流式读写，避免把数万条正文一次性装入内存。

网络采集移植自 BookSift 的贴吧采集架构，使用 `frs/page` 与 `pb/page` protobuf 通道。匿名请求间隔为 1.5–3 秒、每日最多 300 次；BDUSS 档为 1–2 秒、每日最多 600 次。BDUSS 使用 Android Keystore 加密保存，不写入日志或用户备份。用户可设置每吧 1–50 个新帖、每帖 1–300 楼、列表扫描 1–5 页及冷启动 1–50 帖。未全部选择导入时不会推进该吧水位，连续失败会冷却 48 小时。

WebDAV 可使用 HTTPS 服务，也兼容局域网 NAS 的 HTTP 地址；远程使用 HTTP 时，账号和应用密码会在局域网内以明文传输，建议仅在可信网络中启用。Nextcloud、坚果云等支持 WebDAV 的服务通常需要创建应用专用密码。

## 查重

随包数据库保留《扫书宝典》原始行，不执行离线去重。用户导入扫书时仍会按 `canonical_key` 查重，并补充缺失来源；维护脚本仅用于自定义数据处理，不会自动改写当前原始数据库。

维护工具：

- `tools/dedupe_app_content.py`：重建候选桶、复核相似度、合并来源并重建书名聚合
- `tools/filter_meaningless_replies.py`：过滤纯表情、占楼、催更、致谢和低信息短回复
- `tools/filter_recent_short.py`：按日期范围和有效字数阈值清理短内容
- `tools/filter_serialized_artifacts.py`：删除含 `text`、`u3000` 等序列化解析残留的帖子
- `tools/strip_app_search_index.py`：从随包数据库移除 FTS 索引，改由首次启动时生成

## 构建

需要 JDK 17+、Android SDK Platform 35 和 Build-Tools 35。

```powershell
gradle --offline assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。首次启动会把离线数据库复制到应用私有目录；阅读、搜索和数据管理不依赖网络，只有检查更新与手动 WebDAV 备份会联网。

## 技术栈

- Java / Android 原生 View
- SQLite 内置离线数据库
- FTS4 标题、作者与书名索引
- 无第三方运行时依赖
