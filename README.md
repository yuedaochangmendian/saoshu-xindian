# 扫书新典

离线 Android 扫书资料阅读器，界面参考“扫书宝典”的青绿色卡片、粉红色搜索栏与底部导航。

## 下载

GitHub Release 提供：

- Android APK：已签名、可直接安装的应用
- 完整源码包：源码、离线数据库与构建配置

## 数据

- `app/src/main/assets/saoshu.db`：34,508 条内容、18,053 个书名聚合、44,402 次来源关系
- 数据截止：2026-10-20
- 正文完整保留；标题、作者、书名建立本地索引，正文检索在需要时执行
- 已清理 18,668 条与保留项正文相似度均不低于 60% 的重复记录，重复记录的来源关系会合并到保留版本
- 已删除 3 条纯符号、乱码或单字符重复内容
- 已过滤 430 条纯表情、占楼、催更、致谢和无信息短回复
- 已删除全库有效正文不足 10 字的 1,238 条内容
- 已删除含 `text`、`u3000` 等序列化解析残留的 17,644 条帖子
- 安装包不携带 FTS 索引，首次启动时在设备本地生成，以减小 APK 并支持单文件发布

数据库文件约 169 MB，超过 GitHub 对单个普通仓库文件 100 MB 的限制，因此不提交到 Git 历史，而是放在 Release 的完整源码压缩包中。克隆源码后，将 `saoshu.db` 放入 `app/src/main/assets/` 即可构建。

## 功能

- 首页采用内容优先布局，仅保留轻量统计、搜索入口和最近扫书
- 搜索、书库、收藏和数据管理页统一压缩标题、说明和筛选区域，内容更早进入首屏
- 数据管理将扫书导入导出合并为一张操作卡，用户数据备份与恢复合并为一张操作卡
- 标题、作者、书名搜索，标题无结果时自动回退正文检索
- 关键词搜索与标题/全文模式切换，不显示分类或来源标签
- 书库页提供“书名聚合 / 名词解释”并列视图，直接替换内容区以避免界面叠加异常；42 条名词解释以可点击卡片展示，退出详情后恢复原滚动位置
- 底部导航移除搜索标签，全文搜索改为从首页入口进入，并可返回进入前的页面
- 书名聚合、相关评论与楼内回复阅读
- 书名聚合卡片固定占满列表宽度，使用 70dp 最小高度并兼容系统大字体
- 收藏、复制正文、打开原帖、多来源记录
- 上一篇/下一篇
- 本地删除、收藏与书库同步隐藏，可一键恢复
- 导出全部未删除扫书数据为 UTF-8 JSONL
- 导入扫码备份，按 `canonical_key` 查重并补充缺失来源
- 自绘 `FeedbackTextView` / `FeedbackLinearLayout` 统一处理水波纹、按压状态和触觉反馈
- 底栏由专用 `NavTabView` 直接接管触摸并在抬手时切换页面；点击震动默认关闭，可在数据页开启
- 卡片整块可点击；底栏为固定悬浮的纯图标导航，高度 52dp，不使用模糊效果
- 扫书正文自动整理字段、段落和重点标题
- 隐藏正文中的来源标注和合并记录，标题去除回复、楼中楼、时间和图片残片
- 松石绿、海盐蓝、琥珀棕、樱雾粉、暮云紫五种主题

## 数据管理

底部“数据”页提供：

- **导出扫书**：通过系统文件选择器保存 JSONL，包含正文、分类、书名关联与全部来源关系
- **导入扫书**：逐行读取并查重；新增内容会同步进入搜索和书名聚合
- **本地删除**：阅读页可删除单条内容，原内置数据库不受影响
- **恢复本地删除**：恢复所有本机隐藏记录
- **单条导出**：阅读页可将当前扫书及全部来源导出为独立 JSONL
- **剪切板导入**：先弹出可编辑多行文本框并预填剪切板，确认后识别多条扫书并自动去重
- **用户数据备份**：导出并恢复收藏、简记、主题颜色和震动设置
- **检查更新**：通过 GitHub Release 比较版本并打开新版 APK 下载页
- **更新镜像**：可选择 GitHub 原站、ghfast、gh-proxy 或 ghproxy 下载源
- **收藏与简记合并页**：收藏内容与本地便签使用同一个搜索框和统一列表，置顶简记优先、其余按日期混合排序；简记支持自动保存、置顶、软删除和回收站

导出文件采用流式读写，避免把数万条正文一次性装入内存。

## 查重

内置数据库按正文标准化结果计算查重指纹，并使用标题、前缀和后缀候选桶与完整文本相似度复核。当前公开数据维护阈值为 60%，详细删除日志只写入本地 `outputs/`，不提交到仓库。

维护工具：

- `tools/dedupe_app_content.py`：重建候选桶、复核相似度、合并来源并重建书名聚合
- `tools/filter_meaningless_replies.py`：过滤纯表情、占楼、催更、致谢和低信息短回复
- `tools/filter_recent_short.py`：按日期范围和有效字数阈值清理短内容
- `tools/filter_serialized_artifacts.py`：删除含 `text`、`u3000` 等序列化解析残留的帖子
- `tools/strip_app_search_index.py`：从随包数据库移除 FTS 索引，改由首次启动时生成

## 构建

需要 JDK 17+、Android SDK Platform 35 和 Build-Tools 35。

```powershell
gradle --offline assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。首次启动会把离线数据库复制到应用私有目录，随后完全离线运行。

## 技术栈

- Java / Android 原生 View
- SQLite 内置离线数据库
- FTS4 标题、作者与书名索引
- 无第三方运行时依赖
